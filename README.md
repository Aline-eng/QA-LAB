# QA-LAB

This repository contains QA labs — structured, hands-on exercises, templates, and reports for learning and practicing quality assurance techniques.

Current lab folders:

- QA Fundamentals/ — foundational materials and reports (including the [Test Strategy Report](https://github.com/Aline-eng/QA-LAB/blob/main/QA%20Fundamentals/Test%20Strategy%20Report.md)).

Submitting your first lab

1. Create a new top-level folder with a clear name for the lab (e.g., "Performance Testing").
2. Add your lab files, notes, and any supporting assets inside that folder.
3. Include a short README in the lab folder describing objectives and key artifacts.

If you need help organizing labs or want a template for new lab READMEs, open an issue or create a PR and I can add a CONTRIBUTING.md and a lab README template.
