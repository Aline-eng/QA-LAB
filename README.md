# QA-LAB

This repository contains QA labs — hands-on exercises, templates, and reports for learning and practicing quality assurance techniques.

Folders are used to organize each lab. Current lab folders:

- QA Fundamentals/ — foundational materials and reports (e.g., Test Strategy Report)

How to add a new lab:

1. Create a new top-level folder with a clear name for the lab (e.g., "Performance Testing").
2. Add your lab files, notes, and any supporting assets inside that folder.

If you need help organizing labs or want to add a lab guide, open an issue or create a PR.
